Where do I find the A code?
  1. Open Light Remote Local Wall on the computer (Windows: tray icon).
  2. Choose the A/B approval or Connect to AI action, then copy the fresh A code.
  3. Open the official ChatGPT plugin and send the A code to the Connection Helper.
  4. Enter the B code returned by ChatGPT into the same Local Wall → /approve and select Approve.
  5. Return to ChatGPT, say you approved the code and continue only after the helper reports ready.

Enrollment links a computer to your account; A/B authorizes ChatGPT separately. Never share pairing codes with support.
