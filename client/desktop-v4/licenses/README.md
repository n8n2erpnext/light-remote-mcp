# Bundled typography attribution
The UI references the existing tracked variable font asset at `assets/fonts/web/GoogleSans-Variable.ttf` by relative Vite CSS asset import. It is **not duplicated** in this package. Vite/GitHub Actions bundles a hashed copy with the production webview build. This font's internal family metadata is **Google Sans**, not **Google Sans Flex**, which is how the design font was described in Figma.
Original source package: `/home/ubuntu/n8n2erpnext/Google_Sans,Google_Sans_Code/Google_Sans/`, matching sha256 `e4400e3891cb4677fb21834d29de2371d4a4831a47d462e5b9433e5b23ba5c73`. The license is `GoogleSans-OFL-1.1.txt` and governs the existing original font. No font glyphs or metadata were modified.
The stylesheet uses the unique application alias `Light Remote Google Sans` to make the browser select the bundled face ahead of Windows system fallbacks. Exact typography parity with an independently supplied `Google Sans Flex` font remains pending verification if that is a distinct typeface.
