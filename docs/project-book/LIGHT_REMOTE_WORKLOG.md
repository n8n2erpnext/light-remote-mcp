## 2026-10-30 — A/B V2 approval TTL decision: 5 minutes; legacy V1 unchanged
Before proceeding with P2-I1/I2 implementation, checked `operator-host/device-pairing-registry.mjs`: real legacy A code defaults to `DEFAULT_PAIRING_CODE_TTL_MS = 3 * 60 * 1000` and currently allows configured bounds of 30 seconds to 10 minutes. The six-character immutable device Short ID remains visible indefinitely, the five-character temporary A suffix and independently issued B expire with the same pending request, with no timeout extension from polling/page reload/failed entry. One-time use, hard approval deadline, exact device/actor/request binding, rate limits, revocation and 24-hour approved A/B lease are mandatory. Legacy V1 TTL remains three minutes for client compatibility. This is a design/documentation decision; V2 protocol and timeout are NOT yet deployed or wired to live runtime.
