# Light Remote Documentation Library

Status: canonical-navigation
Date: 2026-10-30

Start at [Project Book](project-book/README.md). Before adding or moving documentation, read [Library Rules](project-book/LIBRARY_RULES.md).

The repository already has historical Gold, optimization, releases and operational documents. These documents **have not been bulk-moved**: some paths are referenced by code, scripts, CI or handoffs.

The [Document Library Map](project-book/DOCUMENT_LIBRARY_MAP.md) locates authority; the [Code Map](project-book/LIGHT_REMOTE_CODE_MAP.md) locates executable boundaries; the [Source Catalog](project-book/SOURCE_CATALOG.md) and [JSON catalog](project-book/source_catalog.json) provide exact bookmarks and SHA-256; the [Worklog](project-book/LIGHT_REMOTE_WORKLOG.md) preserves chronology. For current working position, read `.light-remote/CURRENT_CHECKPOINT.json` after the Project Book rules.

**Source precedence:** exact deployed runtime and current code/Git/CI evidence > verified current contract > approved product decision > dated handoff > historical notes. A source-verified fixture PASS does not imply live deployment or owner sign-off.
